# Home Medicine Box

隐私优先的家庭药箱管理工具。

公开仓库只用于官网、PWA 体验页和安装包下载，不包含客户端源码。

## 在线体验

GitHub Pages:

```text
https://wonkmy.github.io/home-medicine-box/
```

## 下载

GitHub Release:

```text
https://github.com/Wonkmy/home-medicine-box/releases/latest
```

本仓库也提供服务器本地下载包：

```text
pwa/downloads/home-medicine-box-android-arm64-v8a-v1.0.0.apk
pwa/downloads/home-medicine-box-windows-x64-v1.0.0.zip
```

## 隐私

Web 体验版数据保存在浏览器本地。

完整 App 默认使用本地存储，账号服务只记录账号和订阅状态，不保存药箱、药品和用药记录。
